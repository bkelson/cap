# Roadmap

Cap is a hobby project made in the open. This is a plan, not a promise: there are no dates, and the order can change. Each item is marked:

- **Done**: it is in the app today.
- **Planned**: we intend to build it.
- **Exploring**: we are finding out whether it can be done well. It may not happen.
- **Idea**: a direction we like, with no commitment.

The vision behind it: *make the costs of AI visible, so using it responsibly becomes a habit.* See [VISION.md](VISION.md).

## Phase 1: A dependable core

*Make Cap stable, easy to install, and right about the basics.*

- **Done:** menu bar dial and figures (Compact and Expanded), popover, pinned widget (Small, Medium, Strip).
- **Done:** first-run welcome window; works with Claude Code or the Claude desktop app.
- **Done:** limit alerts, signed-out alerts, one-click sign-in, daily update check against GitHub.
- **Planned:** notarization, so macOS stops showing the "cannot verify the developer" warning.
- **Planned:** one-click updates, once Cap is notarized.
- **Planned:** a short FAQ, and a contributing guide so people can help.
- **Planned:** extra-usage status (whether you are using paid overage), which Cap can already see.
- **Planned:** a VoiceOver and keyboard check, so Cap works for everyone.
- **Idea:** install with one line through Homebrew.

## Phase 2: More to see, more ways to see it

*Show more of what matters, and let people shape Cap without making it complicated.*

- **Exploring:** token usage, shown locally. This depends on finding a reliable source on your Mac that needs no new credentials.
- **Exploring:** usage history, so you can see your week and not only now.
- **Planned:** a few more well-chosen options for how and where Cap appears (for example, a look override for the popover and widget).
- **Exploring:** a modular design, so extra readings can be switched on without crowding the basics.
- **Exploring:** Cap Labs, a clearly marked place for experiments, with their data use shown beside each one.
- **Exploring:** more usage sources, starting with Claude API usage. Today this needs an organisation key, which conflicts with Cap's rule of never taking a credential, so it only happens if it can be done openly and by choice.
- **Exploring:** pacing: "at this rate you will reach your limit around 3 pm", so you can adjust before the wall, not after.
- **Idea:** real Mac widgets for Notification Center, and actions for Shortcuts.
- **Idea:** exporting your own history; more languages.

## Phase 3: Informed choices

*Where we are headed. Nothing here is built, and each part only happens with a method we can defend and show.*

- **Exploring:** estimates of the energy and water cost of your AI use, always labelled as estimates, with their method visible.
- **Idea:** a weekly summary of what your AI use cost, in terms you can act on.
- **Idea:** a quiet nudge when a conversation has grown long and starting fresh would cost less.
- **Idea:** a per-project view of where your usage goes.
- **Exploring:** an open, written methodology for every estimate, reviewed in public, ideally with researchers who measure this for a living.
- **Idea:** an open guide to lighter prompting, written for people, not only for Cap users.

## Beyond: dreams, not plans

*Reaching further. None of this is planned, and some of it may turn out to be a bad idea. We would rather write it down and cross it out later.*

- **Idea:** efficiency insights, to help you use Claude more thoughtfully. Anything of this kind would run only with your explicit say-so, and would explain what it reads before it starts.
- **Idea:** a companion for iPhone, iPad or Apple Watch, so your limits follow you.
- **Idea:** a small, local interface so other tools can read Cap's numbers, and a way for the community to add readings as modules.
- **Idea:** opt-in, anonymous comparisons ("how does my usage compare?"), only if it can be done with no personal data and with the community's trust.
- **Idea:** a view for teams and organisations that want to understand their shared footprint.
- **Idea:** a public, open dataset of aggregated, anonymous usage patterns for researchers, only if it can be made safe.

Have an idea, or expertise in measuring the footprint of AI? Open an issue.
